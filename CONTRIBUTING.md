# Contributing to AI-Native Company Builder

Thank you for your interest in contributing! This project helps founders build AI-native companies.

## How to Contribute

### 1. Share Your Success Story

If you've used the AI-Native Company Builder to design your company:

1. Create a new file in `/examples/` named `YOUR_COMPANY_NAME.md`
2. Include your input context and key insights from the output
3. Share metrics (optional): customers, MRR, timeline
4. Submit a PR

### 2. Improve the Prompt

Found ways to make the prompt better?

1. Fork the repository
2. Edit `SUPER_PROMPT.md` with your improvements
3. Test with an AI assistant (ChatGPT/Claude)
4. Submit a PR with before/after examples

### 3. Add Examples

More examples help everyone:

1. Create example outputs for different industries
2. Add to `/examples/` directory
3. Follow the format in `EXAMPLE_OUTPUT.md`
4. Submit a PR

### 4. Fix Issues

Check the [Issues](https://github.com/EdisonTKPcom/Ai-Native-Company-Builder/issues) tab for:

- Documentation improvements
- Prompt refinements
- Template enhancements
- Bug fixes

## Guidelines

- **Keep it actionable:** Focus on execution, not theory
- **Be specific:** Use real examples, not generic advice
- **Test thoroughly:** Run prompts through AI assistants before submitting
- **Document changes:** Explain why your change improves the output

## Code of Conduct

- Be respectful and constructive
- Focus on helping founders succeed
- Share knowledge generously
- Give credit where due

## Questions?

Open an issue or reach out to the maintainers.

Thank you for contributing! 🙏
