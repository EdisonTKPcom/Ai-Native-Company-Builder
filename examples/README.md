## How to Add Your Example

Built something with this prompt? Share your blueprint!

1. Create a new file: `YOUR_COMPANY_NAME.md`
2. Include:
   - Your input context (industry, ICP, problem, budget, etc.)
   - Key sections from your output (at least North Star, Product Strategy, Build Plan)
   - Optional: Metrics/results after executing
3. Submit a PR

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines.
